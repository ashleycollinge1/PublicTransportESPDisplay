# Public Transport (Tram/Bus/Train) for Lace Market

## Trains

Gets and displays the next trains available to travel to Beeston or Long Eaton and the platform.

## Trams

Gets and displays the trams coming and going at the Lace Market Tram Stops with times.

## Buses

Gets and displays the times for buses leaving from BroadMarsh Bus Station (Skylink) and leaving from Friar Lane (i4 and Indigo)

## Diplaying

The data will be collated and displayed in a console window, updating every 30 seconds.

The data will also be available through a simple web api. This is to allow an ESP32 device to poll the data and display all of it on a small screen mounted somewhere on the wall.
